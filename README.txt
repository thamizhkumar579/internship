WEEK 1 - HTML BASICS

Files:
1. index.html       -> Heading, paragraph, image, list and navigation
2. students.html    -> Student table with names, roll numbers and marks
3. register.html    -> Registration form with input, select and buttons
4. css/style.css    -> Simple styling
5. images/html-project.svg -> Local image used in index.html

HOW TO RUN:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html using Live Server, or double-click index.html.
4. Use the navigation links to open Students and Registration.

NOTE:
The form is a front-end HTML form. The Submit button will not save data to a database because no backend has been added.
